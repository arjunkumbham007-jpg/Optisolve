About OptiSolve

OptiSolve is an interactive linear programming (LP) learning tool. It combines a C++ optimization engine with a web interface and Manim-generated videos to make the process of solving a linear program easier to inspect.

Methods supported

Standard Simplex: for models supported by the feasible slack-basis setup.

Two-Phase Simplex: uses a feasibility phase before optimizing the original objective when artificial variables are needed.

Big-M: uses artificial-variable penalties; numerical results may be sensitive to model scaling, so comparing with Two-Phase is sensible for difficult cases.

Algorithm walkthroughs

For recorded steps, OptiSolve can display tableaus, reduced-cost choices, minimum-ratio candidates, pivot operations, and phase transitions. For two-variable models, it can also generate a graphical explanation of the feasible region and candidate solution.

Natural-language model input

The parser is deliberately conservative. It handles explicit formulas described with supported mathematical phrases, then fills an editable draft. It does not reliably infer a complete LP model from arbitrary business narratives. Always review the objective, coefficients, relations, and right-hand sides before solving.

Limitations

The web interface currently accepts up to 20 decision variables and 100 constraints. Graphical explanations are limited to two variables. OptiSolve is an educational project, not a substitute for independently validating consequential optimization decisions.
