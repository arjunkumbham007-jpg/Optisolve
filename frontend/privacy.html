Privacy notice

This notice describes the current OptiSolve public-demo design. Update it to match your final hosting provider, logging, retention settings, and any analytics before launch.

Data submitted

When you solve a model, OptiSolve receives the coefficients, constraint relations, right-hand sides, selected algorithm, and optional formula-style text sent to the parser. The current parser is local and deterministic; this build does not send the text to an external LLM provider.

Temporary files

For each solve, the server stores a job-specific JSON result and generated MP4 files so the browser can load them. Job files are automatically pruned according to the configured retention period (default 24 hours) and storage cap. Anyone who has a job's unguessable video URL may access those artifacts until they expire; do not submit sensitive or confidential models to this demo.

Technical logs

The web server and hosting provider may process technical connection metadata such as IP addresses, request paths, and timestamps for security and operations. Review your host's logging and retention settings before publishing.

Educational use

OptiSolve is provided as an educational project. Do not submit personal data or confidential business information. The operator should replace this placeholder notice with contact details and jurisdiction-specific disclosures appropriate for the actual deployment.
